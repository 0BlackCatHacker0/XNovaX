PACKAGE MANAGER KNOWLEDGE MAP

System Level
apt -> Debian/Ubuntu packages -> dpkg -> system libraries
dnf/yum -> RedHat/Fedora packages -> rpm -> system libraries
pacman -> Arch packages -> system libraries
brew -> macOS libraries -> /usr/local
winget -> Windows apps installer
choco -> Windows package manager
scoop -> portable Windows apps

Language Level
pip -> Python packages -> site-packages
poetry -> Python project dependency manager
npm -> Node.js packages -> node_modules
pnpm -> symlinked node_modules store
yarn -> JS dependency manager
cargo -> Rust crates -> target build artifacts
go mod -> Go modules cache
gem -> Ruby gems
composer -> PHP packages
nuget -> .NET assemblies
maven -> Java jars
gradle -> Java/Kotlin build & deps

Container / Env
docker -> images -> containers
conda -> scientific python environments
nix -> reproducible system environments

Relationship Rules
system package managers install compilers
language package managers install libraries
containers isolate environments
build tools orchestrate dependencies
