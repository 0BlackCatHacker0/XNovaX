OPENCLAW DASHBOARD BIBLE — COMPLETE DEEP REFERENCE

This document is a comprehensive operational breakdown of every major
OpenClaw dashboard section, configuration path, security model, autonomy
mode, and advanced usage architecture.

OpenClaw is a permissioned AI execution control plane designed to bridge
large language models with real operating systems.

  -------------------------------
  SECTION 1 — CORE ARCHITECTURE
  -------------------------------

OpenClaw operates across 7 primary layers:

1.  Dashboard UI (Human Control Plane)
2.  Agent Runtime (Cognitive Engine)
3.  Tool Router (Permission Firewall)
4.  Execution Layer (OS + Apps + Browser)
5.  Memory Layer (Persistent Context)
6.  Automation Engine (Triggers + Rules)
7.  Safety & Approval System

Each layer can be configured independently.
